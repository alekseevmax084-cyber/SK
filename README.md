# СК Элит — кабинет прораба

Веб-приложение для объектов, задач, предписаний, дополнительных работ, документов, учёта рабочих смен и месячной сводки для бухгалтера. Интерфейс на русском, адаптирован для телефона и компьютера.

## Локальный запуск

Нужен Node.js 24. Установка пакетов не требуется: используются встроенные модули Node.js.

```sh
npm run dev
```

Откройте `http://localhost:4173`. Данные локального запуска хранятся в `.sites-runtime/preview.sqlite`, файлы — в `.sites-runtime/files/`. Эти данные не включаются в Git.

## Сборка

```sh
npm run build
node --check dist/server/index.js
```

Результат — Cloudflare Worker в `dist/server/index.js`. Настройки существующего размещения Sites находятся в `.openai/hosting.json`.

## Структура

- `index.html` — интерфейс, стили и клиентский JavaScript.
- `worker/api.js` — API для записей и файлов.
- `scripts/dev.mjs` — локальный сервер с SQLite и файловым хранилищем.
- `scripts/build.mjs` — сборка Worker.
- `drizzle/` — миграции базы для размещения Sites.
- `migrations/` — SQL-схема для локальной разработки.

## Размещение и доступ

GitHub хранит исходный код. GitHub Pages не исполняет серверный API этого приложения и не заменяет базу данных и файловое хранилище.

Текущая рабочая версия размещена в Sites. Вход через ChatGPT и ограничение доступа обеспечивает платформа Sites, а не код Worker. Для независимого размещения потребуется настроить собственную авторизацию перед всеми страницами, API и скачиванием файлов, создать базу Cloudflare D1 с привязкой `DB`, применить схему и подключить Cloudflare R2 с привязкой `BUCKET`. База и загруженные файлы автоматически через Git не переносятся.

## Работа с приложением

Пустая база открывается с демонстрационными данными. Нажмите «Перейти к моим данным», добавьте объекты и рабочих, затем задачи и смены.

Часы смены считаются за вычетом перерыва. Если конец раньше начала, смена считается ночной. Отсутствие даёт 0 часов. Предварительное начисление равно часам за месяц, умноженным на текущую ставку рабочего; налоги, удержания и авансы не рассчитываются. Изменение ставки пересчитывает сводку.

## Что не следует добавлять в репозиторий

Не включайте токены, пароли, локальную базу, документы работников и загруженные файлы. Для рабочих исходников рекомендуется закрытый репозиторий.
